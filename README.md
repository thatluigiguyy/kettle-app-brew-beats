# 🎹 Brew Beats

Make songs with a piano roll and drums, like a tiny FL Studio, and export them as MP3.

- Click the grid to add notes. There are four instruments: piano, synth, bell and organ.
- Kick, snare, hi-hat and clap rows for drums.
- Play, Loop, BPM, and Export to MP3 (it saves in your Music folder).
- Your song is saved automatically.

Version 1.1 by @thatluigiguyy

Made with **Kettle Studio** on [Kettle Linux](https://github.com/thatluigiguyy/kettle-linux). Install it from the **Kettle Store**.

## No sound?

Sound comes from the Kettle SDK, which is newer than the first Kettle Linux 1.0 download. Open a terminal (Konsole) and run this once:

```
curl -fsSL https://raw.githubusercontent.com/thatluigiguyy/kettle-linux/main/apps/update.sh | sudo sh
```

After that, `kettle-update` keeps Kettle's apps up to date.
